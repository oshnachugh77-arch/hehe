# Your Programming and AI syllabus

Open the Phase-0 through Phase-5 folders in the file explorer. They contain your
lessons, notebooks and exercises; shared datasets are in the datasets folder.
You do not need to clone a repository or use Git to get started.

This is your personal, editable copy. Your changes stay here when the workspace
stops or restarts. The template does not reset or overwrite this folder.
Keep your other projects alongside Syllabus in the project folder.

Each workspace has a 0.5 CPU quota, 2 GiB RAM and a 5 GiB disk shared by your
files and temporary files. GPU/CUDA and Ollama are unavailable. GPU instructions
in the original repository README do not apply to these workspaces.

Different templates have different software installed. Use the AI template for
its preinstalled Python and Jupyter environments, and the web templates for web
development. Course files are provided in every template; this does not install
all dependencies for every lesson.
